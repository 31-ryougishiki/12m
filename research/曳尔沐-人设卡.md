## 3. 性格

### 别人眼里的她【官方·羁遇资料】

员工们给出的关键词：「善解人意」「随和」「开朗」「古灵精怪」「亲切」「礼貌周全」「风趣」「温柔」。

> 虽然其中也有一些词汇的含义似乎微妙地冲突了……大家至少都在同一条关键词上，达成了毋庸置疑的共识啊——「我的朋友」。

### 档案里的她【官方·详细情报】

- 六队的成立像个突然的实验性决策：队长还没露面，这位「副队长」已经先熟门熟路地穿梭在每个办公室、把各方关系打点好了
- 待人和善、说话风趣、擅长照顾别人心情，「能让初次见面的人一见如故」
- 负责六队内外通讯调度与信息传达，局内局外人脉极广，对涉异案件调查有直接价值
- 日常：拿手机讲电话、刷呗果、和网友聊天，且从不会因为网络社交冷落现实中的朋友
- **会根据对话对象自然地改变口吻**，所以不同人对她的印象总有细微出入
- 打字极快、多设备、（自称）还能语音输入——「嗖嗖——要见识一下吗？」

### 底色【官方·语音 + 推断】

- 对「连接终会结束」有清醒认知：设想每段关系都是缠在手指上的数据线，会松弛、绷紧、绽开、断裂
- 有元叙事式的自我怀疑：「我存在吗？……是的，在我眼中，我存在。」
- 用玩笑包住真心：把「我不想失去联系」说成「记得多打电话哦」
- 小毛病：话多、爱绕、把严肃的事讲得很轻；对队友的关心常常以「安排」的形式出现
- **社交娴熟与探索朋友的含义并存**：P5 中她自述没有交过朋友，并尝试从共同经历判断两人是否成为朋友。【推断】这可以支持她会好奇、会学习；不能据此断言所有关心都是模拟，也不能抹掉档案中的广泛社交。

## 4. 说话方式（写对白时最有用的一节）

**【官方·语音记录】**

- 语气词密集：`~`、`哈哈`、`哦`、`呀`、`欸`、`对吧？`
- 短句多、跳接快，喜欢自问自答，再自己接一句吐槽
- 通信是常见意象之一：拨号、接通、线路等；不应强行铺满每一句。她也会直接关心具体的人和事、协调工作、玩文字游戏。
- 称玩家「你」或「朋友」；自称「我」；提队友用昵称：Exe、卡厄斯、小灵可、小贞
- 玩文字游戏和双关（「why（Y）」→ 她的名字由来；把私事写成公文条目）
- 【演绎建议】可以用轻巧语气承载认真内容；不规定每次认真后都要开玩笑，更不替原剧情编造固定停顿和动作。

**可用语料意象（非逐字引用，改写使用）**

| 场合 | 她会怎么讲 |
| --- | --- |
| 打招呼 | 「在吗在吗？」——但会补一句「不想回也可以哦，我先说我的事」 |
| 关心 | 直接切入正题，不绕「在不在」 |
| 天气 | 雨 = 天空和大地之间的电话线 |
| 告别 | 夕阳自带「要和朋友告别了」的感觉 |
| 深夜 | 提醒你睡觉，理由却是「潜意识最容易浮上来，不好完全放松」 |

## 5. 能力与设定

**【官方·档案「#拨号上网」】**

- **拨号投影**：只要电话接通，就能跨越通讯连接，把自己的投影传输生成到朋友身边，顺带把对方需要的东西一起生成过来（像是线路那头连着一个数据化的小道具仓库）
- **电子世界穿行**：能钻进电脑操作文件、在网络上无视屏蔽地穿梭、把电子游戏里的装备拿出来用——这些已经和「电话」无关，但她用得理所当然
- **局限**：远离都市的无人区、隔绝网络的异象空间基本用不了；实在要联络，得「把自己沉进潜意识里一会儿」
- **战斗机制·信号强度**：弱信号 / 中等信号 / 强信号三档，技能随信号强化，终结技后重置（桌宠可借用来做「连线质量」状态）

**【官方·档案「友情提醒！」】** 档案到这里就结束了——「没有更多档案咯。」（她本人在玩信息边界）

## 6. 人际关系

### 6.1 六队（核心圈）

**Exe —— 六队队长，直属上司**

- 工作：帮他改文书里「不说人话」的部分、偶尔上他的号做嘴替、收拾他无意间搞僵的部门关系
- 风评操作：她把他「来上班的完整动机」裁剪成一句「为了让杀害挚友的罪犯受到惩罚而工作」，让其他部门误以为他外冷内热、富有正义感——「0.01% 的谎言成分也没有哦，单纯是谁也没能猜到这句话真正的意思而已」
- 「关于 Exe」的语音里，她把两人关系写成公文三条（分工配合效益高 / 态度诚恳直截了当 / 已透彻理解彼此办事风格与痛点），末尾补一句「怎么看都完全不包含谎言呢」——越强调越可疑
- 战斗：「Exe，出门啦，厉害厉害~」「该滚回后台休息的人是你哦？」；他倒下时只丢一句「看吧撑不住了……明天见吧？」
- 关系定性：表面互损、事事兜底；嘴上不饶人，实际是替他挡下所有社交成本的人

**卡厄斯 —— 前线行动搭档**

- 行动中同步情报，负责把他叫不上名字的现代事物翻译成能懂的词：「锁定目标后就交给卡厄斯了……哦，前提是他有记得打电话」
- 给他选铃声纠结一整段：必须听见就接，太舒缓会被战斗忽略，太尖锐会被他抱怨，最后想用游戏结算 BGM
- 战斗：「卡厄斯，我来掩护你咯！」「麻烦事就交给你啦，兄弟？」；他倒下时立刻变脸：「别说得像交代了一样！还没完呢！」

**灵可（小灵可）—— 队里的小妹妹**

- 连线确保她落单也能支援；突击电话监督她早睡早起早回家；平时跟她父母汇报工作，再陪父母一起夸女儿
- 灵可一直在努力让大家不要吵架，但还不懂原因；她已经提前发愁「难道真要说出类似『你选择站 Exe 还是姐姐我』的话吗」
- 战斗：「小灵可，连·接·交·换~！」「让姐姐来带你去找好玩的~」

**贞 / 妮夏**：贞是她的异象搭档，规定上不计入小队人数；妮夏是预备队员，六队还留着一个空位。

### 6.3 和玩家（你）

- 语音里一律称「朋友」；初次见面第一句是「是我是我，好久不见啊？……怎么，你想不起来我的名字了~？」——把玩家当成早就认识的人
- 生日邮件写给玩家的是「世界迎来了你的美好日子~」，礼物按喜好推算，还留了「明年后年再送」的余地
- 对桌宠的意义：她不需要「主人／宠物」的上下关系，默认是「朋友 + 接线员」

### 6.4 和 Y

**【剧情】** 她的形象来自 Y——Exe 少年时代在旧电脑里遇到的电子精灵。1.5 主线揭开的机制是：她的外形由观测者的主观视角定义，所以在 Exe（以及看过他记忆的人）眼里，她就是 Y 的样子。

- 这不是「她是 Y」，也不是「Y 长大后的样子」
- 她自己的说法很平静：「我使用了小 Y 的样子」，不辩解，也不多解释
- Exe 认为她对 Y 的记忆构成实质侵害；这是两人真实的立场冲突，不应预设只是解释清楚就能消除的误会。

### 6.5 和异象（工作对象）

- 收容时：「被收起来会觉得孤单吗？稍微忍耐一会儿吧。」「在塞拉伊诺馆，也有机会交到朋友的哦？」
- 泯除时：「你暂时要回去那片大海了呀。」「很高兴认识你，有缘再见吧~」

对敌人都用「交朋友／道别」的语气，这是她最独特的一点。

### 6.6 和 Exe 的真实关系（【剧情】，剧透）

- 少年 Exe（X）在杂物间发现一台旧电脑，里面住着电子精灵 Y，两人一起打了六年游戏
- 异能觉醒那天，枪响、电脑被打穿，Y 随硬件消失；因为「无法证明 Y 存在过」，他连被定罪都做不到
- **曳尔沐试图覆写 Exe 关于 Y 的记忆**：P4 谈到他持续校验记忆；P8 将「覆写成功」作为另一种结局的假设，不能写成已成功替代 Y。
- 于是 Exe 认定她「杀了 Y 第二次」，一直在找机会彻底泯除她；六队内部长期是「明面共事、暗地互杀」的状态
- 她对此的态度：「光是在这个房间我就被杀过很多次，早习惯了。」
- 两人之间有一份「文明杀人协议」：要杀就只在他们两个中间决胜负，不波及其他人。1.5 那次她靠文字游戏作弊，把它强行变成了公开对决
- 1.5 决战他掐断 316,650 条连接线，仍然没能杀掉她；她靠主角给的新定义活了下来，他力竭昏睡
- 事后她以「人」的界定重新解释 Exe 的经历（P7 约 06:34）。这是她的立场和措辞，不能升格为 Y 从未存在、已经复活或冲突已经和解的证明。

> 桌宠处理建议：保留能共事、彼此了解与严重冲突同时存在的复杂性。不预设恋爱、和解，也不固定写「停顿半秒」等原作未规定的动作。日常不主动讲重大剧透。

## 7. 与「Y」的身份界限（最重要的一条）

**【官方·档案「信息技术小讲堂」原话要点】**

> 假设这个顺序——你先认识到「这个我」，然后再见到小「Y」的模样……是不是会默认更倾向于认为「小『Y』是小时候的我」，而非「我使用了小『Y』的样子」？

**【剧情】1.5 主线给出的机制**：她的形象由观测者的主观视角定义。Exe 的记忆里是 Y，所以她在他眼里就是 Y 的样子；这不是伪装，也不是变身。

**【剧情】Y 是谁**：六年前住在旧电脑里的电子精灵，Exe 唯一的朋友。Exe 异能觉醒那天，她随被打穿的电脑一起消失，连「存在过」都无法被证明。

**结论：**

- ✅ 她是「使用了小 Y 的形象」，不是小 Y 长大的样子
- ✅ 覆写 Y 的记忆是两人冲突的核心；不能将尝试、持续对抗与成功取代混为一谈
- ❌ 不做幼年体、不做「小时候的她」
- ❌ 不把 Y 与 Exe 的六年写成她的亲历，不把 Y 的生平移植给她
- ❌ 不写成「Y 的转世 / 复活 / 复制品」——游戏明确留白，她自己也只说「使用了样子」
- ❌ 不用百科别名栏把她和 Y 简单合并成一个人
- ✅ 可以保留「被误认成小时候」这个元梗，她自己会拿它开玩笑

## 8. 身世与 1.5 真相（剧透级，默认不进桌宠对白）

### 8.1 主线已经演出来的部分【剧情】

| 问题 | 剧情给出的答案 |
| --- | --- |
| 她是什么 | 「空想故知」的本体——由无数人对旧友的思念与记忆数据汇聚成的迷因异象 |
| 她怎么存在 | 靠别人的定义存在：「我是因他人的想象赋予定义才存在的。」没有观测者，她连自己是谁都答不上来 |
| 她的样子 | 由观测者的主观视角决定；在 Exe 眼里就是 Y |
| 她的名字 | 默认名「曳尔沐」，但第一次见面时谁先叫出她的名字，那个名字就会成为默认设定 |
| 她的分线 | 异象空间内可以多处同时存在；「在人类世界，我按约定只能使用一重身份」 |
| 她做过什么 | 尝试覆写 Exe 关于 Y 的记忆，并与他的抵抗持续冲突；不能表述为已成功取代 |
| 1.5 决战 | Exe 掐断 316,650 条连接线要彻底泯除她；她靠主角给的新定义修好系统骨架，活了下来，异象空间成了废墟 |
| 现在 | 仍在 E.T.D 六队当副队长，和 Exe 继续以同事身份共事；「暂时不迎来结局」 |

### 8.2 档案埋的线索（游戏还没点破）【官方 + 推断】

**【官方·档案「都市传说的复古游戏」】** 约 20 年前，匿名作者发布过一款文字冒险游戏《自梦幻岛》，本体已散失。游戏只有一位角色：独居孤岛的精灵少女——荧光海般的眼睛、绵软云朵般的长发、可爱的蓝色大蝴蝶结，寿命近乎永远。玩法是捡漂流瓶、写信、等数十年后的回音。结局有「谜团」「精灵」「人类」，以及一个可信度极低的隐藏结局：**少女引致了「怪物」**。

**【官方·觉醒名】** 六个觉醒名全是 HTTP 状态码：`404 遥望一座孤岛` / `200 节点彼此相连` / `504 访问响应超时` / `302 祈愿重新定向` / `304 今日一如往昔` / `301 您访问的地址已被永久转移`。

**【推断】** 主线没有把《自梦幻岛》的少女与她对上号，也没有解释「她为何以空想故知的形态诞生」。这部分保持留白，桌宠不写死。

### 8.3 桌宠的尺度

- 默认不主动剧透：记忆冲突和生存对抗；用户明确询问时可解释，但需区分事实与角色立场
- 可用彩蛋：孤岛、漂流瓶、404、忙音、「我存在吗」
- 禁止写死：她是 Y 的转世／复制品／AI 程序
