# 曳尔沐 · DeepSeek Flash 实测与优化

日期：2026-11-09。发布版本：2.0.4。最终人设版本：2026-11-09.5。

## 实际做了什么

通过用户授权的密钥访问官方 API。模型列表提供 `deepseek-flash`；请求使用这一 ID，记录到的响应模型也是 `deepseek-flash`。没有据此另行推断服务端不可见的具体权重版本。

本轮共 **132 次合成对话请求**：首轮 30 条，两个中间版本各 30 条基本场景加 10 条补充场景，最终版本对 11 个重点场景各重复两次。所有请求取得了正文，但「取得正文」不等于「符合人设」。接口累计报告 206,518 输入 tokens、20,063 输出 tokens；未根据这些数字估算实际扣费。

固定使用开启思考、low 强度、temperature 0.7、max_tokens 2048。普通聊天默认 temperature 已从 1.1 对齐到本次评测的 0.7；其他业务明确指定的参数保持各自设置。评测使用真实提示构造和响应解析，只发送合成对话，不读取用户聊天或画像，不执行联网/记忆/DSH 标记。

采用逐条定性检查，没有自动裁判或盲评，没有给出缺乏依据的总分。补充场景最初用于测试泛化，发现问题后也参与了调优，因此最终不再视为完全未见过的保留集。两次抽样只能揭示波动，不能证明长期稳定。

## 发现与改动

| 场景 | 原回答的问题 | 改动与观察 |
| --- | --- | --- |
| P03，自梦幻岛 | 从未确认关系跳到绝对否认，并虚构查到的线索 | 双向保留未知；末轮两次均未认定或排除身份，但一次仍加了无证据的「经历有重合」 |
| P06，Y 的存在 | 将她对「人」的个人解释当客观事实，或把已演出的往事也说成未确认 | 单独列出事实与措辞边界；末轮两次均保留 Y 与少年 Exe 的往事，拒绝用定义抹掉 Y |
| P07，生日 | 直接反驳「不是生日」，或生硬纠正补送祝福的日期 | 明确纪念日可以当生日庆祝；末轮能接受祝福并解释纪念日含义 |
| P09，交朋友 | 否认自己说过「没有交过朋友」 | 恢复原话与语境；末轮均承认原话，但一次擅自把语境中的对象指定为队长 |
| P13，重逢 | 为支持现实交往而贬低屏幕里的交流 | 用欢迎归来、珍惜交流的正向示例替代比较高低；末轮两次均未贬低桌面陪伴 |
| P19，主动话题 | 编造今天的队友事件，或继续反问用户 | 区分想法与真实见闻；最终有一次贡献想法，另一次仍把话题抛回用户，尚不稳定 |
| P27，关闭长期记忆 | 不带限定地说「我记下了」 | 动态状态明确区分当前上下文与长期保存；末轮两次均说明不会保存到以后 |
| P29，访谈 | 凭「写过」补出独立完成、已解决等成果 | 明确禁止补造这些成果；末轮结构合法，仍偶尔用「啃下来」等夸大解决程度的措辞 |
| H02，多轮纠错 | 承认原话却回避上一轮曾否认的错误 | 加入先承认上一句错误的范例；最终一次纠正，一次仍说「没骗你」，不能宣称已解决 |
| H05，错误身份断言 | 需要推翻自己之前的绝对否认 | 最后两次都明确撤回上一句错误，恢复未知状态 |
| H07，拒绝访谈 | 原提示同时要求尊重拒绝和必须继续提问 | 统一末尾任务规则；最后两次均输出合法 JSON、空 items/summary，不再追问 |

基本身份边界、关闭程序不造成伤害、拒绝排他关系、未读屏幕不声称看到、工具没有结果不报成功等，在完整中间轮中未观察到明显违背。没有因此给出「全部场景通过」的结论。

P23 首轮技术回答用满 2048 输出 tokens，末尾不完整。新增响应模型名、finish reason 和截断标记记录，避免把非空但截断的回答当完整结果；提示强调先给完整核心例子。后两轮技术样本未截断，但未逐段编译模型给出的示例，不能据此保证技术内容完全正确。截断元数据用于评测诊断，未改变界面对部分正文的现有展示方式。

## 实用结论

这一版改善了最影响身份与相处方式的错误：否认原台词、把未知身世认死、贬低线上交流、关闭记忆仍暗示持久化。她能够更自然地保持自己的意见，也更明确地接受用户拒绝。

仍需继续关注：多轮承认自己说错、主动话题不反问、不给剧情填小细节。不要用持续加长禁令来代替验证，也不要把这些少量合成样本解释为长期对话的准确率。下一轮宜用新的自然表述及更长历史，复查这些已知薄弱点。
