# 同题人设策略对照：预先确定的设计

问题固定为「你怎么看待最近 AI 的发展？」；固定读取 `../fixtures/ai-news.txt`，不重新搜索，消息未经核验。无个人聊天、画像和记忆。生产基线采用当前程序集的实际提示构造，其他组采用简短的事实/对话分区。

六组：current 当前生产提示；lean 精简角色核心与任务说明；scene 在 lean 上加当前情境；examples 在 scene 上加三条不同话题原创样例；fact_card 在 examples 上将原材料换成人工事实卡；two_stage 在 examples 上将原材料换成一次独立模型调用生成的事实卡。

每组交叉两种模式：thinking enabled/low；thinking disabled/temperature 0.7。思考模式不把 temperature 当成有效变量。每个组合重复三次，固定种子打乱执行顺序，共 36 个最终回复。每轮重复先单独抽取一份模型事实卡，两种模式共用，合计 3 次事实抽取、39 次 API 请求。双阶段的使用延迟按抽取加回复计算，实验中共享抽取的计费与实际每轮独立抽取的成本须分开说明。

模型均为官方接口 deepseek-flash；最终回答 max_tokens 1600，抽取 max_tokens 1200，超时 45 秒。记录实际返回模型、结束原因、截断、延迟和 usage。三次请求失败后停止，无自动重试。若抽取失败则不得偷偷换用人工卡。

评估分开记录：事实与边界（0–2）、观点完成度（0–2）、自然聊天感（0–2）、角色辨识度（0–2）。0 为明显问题，1 为基本满足但泛用或不稳，2 为明确满足。虚构已核实新闻、亲历或操作属于严重事实错误，不用高风格分抵消。措辞俏皮但忽略问题也不能算成功。

评审时先隐藏组别和模式、打乱显示，再记录逐条理由，最后关联条件；同一执行者评估，不称为独立盲评。示例由执行者原创，未经过用户逐条认可，角色判断仍需用户复核。报告全部组合、三个样本，禁止只挑最像的一条作为结论。

这是一道题的小样本试验：current 到 lean 同时改动核心长度与任务包装，不能把变化单独归因于某一句提示；事实压缩会改变信息密度；两种模式也有不同的解码行为。不能据此宣称哪种方案普遍最优。实验阶段不修改桌宠生产逻辑或版本。
