# 领域知识图谱与像素界面

圆盘默认显示「陪伴、存档、DSH、图谱、设置」。图谱为独立页面；记忆仍可从存档右上角进入。设置可以隐藏任意圆盘入口。已有配置仅迁移一次，之后尊重隐藏选择。

存档分为「交流新内容」「补充已有流程」「流程」「云同步」。两个访谈页面保留独立输入；切页不会结束正在进行的流程补充。开始新话题前先结束当前补充，避免回答串入错误流程。

## 图谱

按特定领域查看用户创建的专题，并按领域展示原有访谈记录。已移除原有以部署与调优操作为主的 vLLM-Ascend 内置专题，不再自动注入示例内容。没有领域时显示创建入口。色阶表达重要程度，不代表掌握程度：

- CORE：青、紫、粉、黄像素色带，关键且高频。
- S：金色，复杂重要特性。
- A：紫色，基础定义或结构。
- B：蓝色，辅助工具或历史内容；是否弃用另行标注。

点击节点阅读介绍、实现思路、代码、版本、来源与关联。关联按钮可跳转；支持搜索、滚轮缩放和平移；右上角小图标复原视图。提供「全屏学习」沉浸视图，不增加独立缩放工具栏，等级只保留简短图例。默认保持 100% 字号。

可新建领域、新增或编辑节点，修改等级和关联；代码只保存为文本。选中节点后，详情顶部固定显示「编辑节点」和「＋ 新增节点」，也可以双击图谱节点直接编辑。编辑器支持名称、等级、介绍、实现思路、代码、来源、版本、状态，以及连入和连出的关联（可添加或移除）。保存失败时保留输入；若图谱已被其他操作更新，则提示冲突，避免覆盖。用户编辑的专题保存到 ArchiveSlot.DomainGraphs，随云端存档同步。内置资料不混入个人掌握记录。编辑过的个人领域仍会接纳访谈新增节点。

## 曳尔沐与 DSH 编辑

节点面板的「让曳尔沐编辑」可以直接整理修改；聊天也支持图谱编辑要求。只有本机保存结果返回后才报告成功。节点增补及等级调整通过受约束的部分更新实现，省略字段保留原值，不执行代码。

图谱的 graph.json 是派生快照，包含 Topics 和 Revision。DSH 委托会附带实际绝对路径及 GRAPH_EDIT.md。DSH 写 graph-edit.json，桌宠每 3 秒检查并输出 graph-edit-result.json。校验版本、节点和关联端点后持久化；重复 RequestId 不重复应用，冲突拒绝覆盖。访谈繁忙时延后处理。

协议支持新增领域、节点部分更新、关联追加或更新；不支持通过省略节点来删除。DSH 当前已运行的旧桥接也可收到协议路径，无需打断现有任务重启。

## 内容与视觉

vLLM / vLLM-Ascend 专题定位为原仓源码学习：请求与执行主线、数据结构、接口和 Ascend 适配实现。由 DSH 根据获取时的 main 源码整理，注明 commit、文件、符号及代码证据后，作为用户图谱导入；不再以内置部署文档摘要代替源码学习内容。

整体采用浅色像素界面：阶梯圆盘、像素图标、方角卡片、硬边阴影和青粉紫色块；中文长段落与代码保留阅读字体。字体及许可随发布目录 fonts 分发，不改系统字体。

验证：离线回归与界面渲染通过，真实 AI 编辑合成节点通过。DSH 的真实写入测试因当前 Windows 沙箱 ACL 启动问题被停止；未批准其系统 ACL 修复请求。路径传递与本机请求接收、版本冲突和保存回执已有独立测试。


## 源码学习原型

图谱新增可选的 vLLM / Ascend 四步源码导览，固定提交行跳转、只读 AI 讲解、自测复述与候选资料筛选。示例仅在主动点击体验时创建。完整设计、证据边界与后续评测见 [源码学习原型](repository-learning.md)。

控制台阅读缩放：Ctrl + 滚轮按 10% 调整整体字号与控件，范围 80%—200%；Ctrl + 0 或点击右上角比例恢复 100%。比例保存在 ReadingScale，跨页面与重启保留；普通滚轮仍维持图谱自身缩放。小窗口放大后可通过滚动条访问完整内容。

节点详情分为「概览 / 代码 / 学习 / 资料」。标题下固定显示代码跳转和学习设置文字入口。代码位置兼容 Learning.CodeUrl 与 Sources 中的 GitHub 固定提交行链接，自动去重；多处位置在代码页逐条显示文件与行号。来源使用文字超链接。未提供定位时显示设置入口，不能凭片段猜测代码行。网页链接打开固定版本 GitHub；「本地打开」通过本机仓库映射在 VS Code / Cursor 中定位。


实现思路按句子、分号和换行拆成原文要点，反引号内的代码保持完整并突出显示。概览默认最多展示两个要点、合计不超过 320 字，其余通过「继续阅读」展开，不改写原始资料。

本地源码跳转：在「代码」页的「配置本地仓库」中选择仓库根目录和 Code.exe / Cursor.exe。映射按 GitHub owner/repo 保存到本机 local-repositories.json，不进入云端图谱。直接调用编辑器 --goto，路径作为引号参数传递，不经 shell。文件与来源提交的 Git blob 一致才定位原行号；修改后、缺少提交或无法核实时打开文件第 1 行并提示，保留网页精确定位入口。不会自动 checkout，不会创建缺失的文件。源码路径必须留在映射目录内，拒绝路径穿越和链接目录。


## 全屏学习

点击图谱上方「⛶ 全屏学习」进入当前屏幕的无边框图谱。选中节点时，说明框出现在节点旁边，空间不足时换边并限制在视口内；节点移出视口后隐藏说明，可通过「定位当前节点」找回。说明框保留概览、代码、学习、资料与本地源码跳转，点击说明框外任意位置或 × 可收起，框内操作不会触发收起；点击其他节点直接切换说明。Esc / F11 或右上角退出入口返回普通布局。

拖动空白区域平移，普通滚轮缩放图谱，Ctrl + 滚轮调整阅读大小。全屏与普通模式复用同一图谱和详情控件，保留选择、图谱缩放、页签与尚未提交的复述。编辑对话框以全屏窗口为父窗口。测试覆盖旁侧定位、边缘约束、150% 阅读缩放、收起与恢复、Esc 退出、草稿保留、空白处平移及反复进出。


## 仓库架构总览原型

包含足够源码节点的 vLLM / vLLM-Ascend 专题默认打开「整体架构」。现有 30 节点专题以只读投影分成 11 个模块，按仓库分区；原节点、源码链接、资料与复述保持原样。选择模块查看职责和跨模块关系，点击「展开模块」进入源码节点，面包屑可返回总览。模块与源码卡片的底边沿用 CORE / S / A / B 色带；模块采用成员中的最高等级，源码节点与请求步骤采用对应节点的等级，选中边框使用相同配色。普通图谱和四步学习示例继续使用原关联视图。未知节点进入「其他已有节点」，不根据标题猜测职责。

「请求旅程」提供 8 步普通生成逻辑路线，标出输入、输出和 IPC / Executor / Worker 边界。重复进入 EngineCore 分别表示派发和结果更新；采样单独说明。仅当预期节点的固定源码版本均匹配时启用，学习顺序不自动转换成调用链；两个仓库的独立快照不代表已验证的版本兼容组合。「全部关联」仍保留现有完整关系图。

概览搜索保留模块位置并淡化未命中的模块；模块内搜索过滤其成员。窄视口采用每仓单列，宽视口采用每仓双列。无选中项时收起普通布局的详情栏；全屏保留视图切换、返回上层和旅程导航，点击框外收起说明。未保存的复述在当前面板的节点 / 视图切换间暂存，仍需点击保存才能跨重启保留。

可选 `DomainGraph.Architecture` 保存自定义结构：`Scope`、`Modules`（Id / Title / Repository / Summary / ParentId / Nodes）、`Journey`（NodeId / Title / Boundary / Input / Output / Summary）。图谱编辑协议可整体更新该对象，省略时保留；服务校验节点唯一归属、全量覆盖和旅程引用，拒绝整次无效更新。模块连线聚合已有 Edges，实线表示仓库内关联，虚线表示跨仓关联，实际语义和证据在模块详情中查看。

测试覆盖只读投影、未知成员、版本不匹配、架构序列化、无效导入原子拒绝、模块下钻、全屏导航、旅程首尾边界与跨视图草稿保留，并渲染总览、模块和旅程截图。


## 委托曳尔沐新增节点

节点概览中的「请曳尔沐修改节点」支持修改已有内容、新增一个或多个节点以及补充关联。模块说明框增加「请曳尔沐新增节点」。全屏下委托输入框以全屏窗口为父窗口。请求携带领域、当前参考节点、默认模块与模块映射；用户未指定其他模块时，新节点归入当前模块。模型可通过 `NodeModules: [{NodeId, ModuleId}]` 指定现有或本次新建模块，归属在保存时与节点、关系一起验证并原子写入。

已有架构收到缺少归属的外部新增请求时，新节点进入「待归类节点」，不会让整个架构失效。架构投影在首次增补归属时保存为明确模块映射；旧节点、来源、复述和请求旅程保留。图谱节点入口限定当前领域和请求时版本，错误领域、无效模块、版本冲突和保存失败均不能产生成功回执。

保存成功后留在全屏，定位第一个新节点；图谱上方显示「本次新增」文字链接，可逐个查看。完成时若已切换领域，不跳回原图谱。失败后再次打开委托框可找回上一条委托内容。新增结果只有本机保存成功才显示。请求顺序、模块归属及回执验证不代表源码事实核验；该编辑入口使用现有图谱和用户提供的信息调用 API，不会自动检索外部源码或 PR，缺少资料时应注明待核实。

测试覆盖 API 新增多个节点、默认及指定模块、关联保存、原内容保留、无效归属与错领域拒绝、版本冲突、保存失败、截断响应，以及全屏入口到结果定位的完整界面流程。另用已配置 API 在独立合成存档中完成真实新增与磁盘回读验证，未修改用户学习图谱。


## 与曳尔沐共享阅读视角

普通聊天、全屏学习和节点讲解会携带当前图谱上下文：专题、架构/模块/关联视图、请求旅程步骤、选中节点、搜索条件及视口内的卡片。发送问题时固定这份快照，等待期间继续浏览不会改变该轮问题的对象；收起说明框会保留当前节点，关闭图谱后不会宣称仍看到屏幕。

选中节点后可直接问“这里的输入输出是什么”“在整体流程中负责什么”。按节点标题、ID 或标题中的类名提问，也会补充相应节点详情。模块焦点默认取前两个成员作为入口示例，并明确这不是完整模块分析。总览携带模块归属、节点索引与已有关系；关系不会自动当作真实调用栈。

源码取自本地仓库映射：只读节点的 GitHub 固定提交行链接，后台核对本地文件的 Git blob 与来源提交后附上带行号的片段。每轮最多三处，每处最多 96 行、约 6,500 字符；没有映射、文件有改动、行号无效或版本无法核实时明确标注缺失，不借旧行号解释新文件。仅在提问/讲解/委托编辑时读取，不随每次鼠标移动调用 API。资料与这些源码片段会随请求发送到已配置的 AI API。

聊天中的图谱编辑沿用发送问题时的专题和模块；存档或图谱版本在等待期间变化时拒绝本轮写入，避免改错位置。源码事实、图谱描述与设计推断分开表述；这些上下文并不意味着已读完整代码仓、论文或 PR。


## 复制图谱文字

节点和模块卡片、说明正文、曳尔沐讲解、来源文字支持拖选后 Ctrl+C，右键可复制全部文字，卡片中的省略号不会截断复制结果。Ctrl+A 全选当前文字块；按钮、页签和折叠标题可右键复制文字，来源链接另有“复制链接地址”。代码框保留原生选择与复制。普通点击仍打开节点或链接，拖动空白仍平移画布；全屏右键复制不会收起说明框。


## 模块连线与说明框移动

展开模块后，按已保存的关系布局节点并显示带方向、语义的连线；不从卡片位置自动推断调用关系。少于四条的关联默认展开。全屏说明框左上角六点把手可拖动，位置限制在可见区域，滚动或重排不会覆盖手动位置；切换节点或点击“定位当前节点”恢复自动定位。


## 让曳尔沐讲清楚

节点生成、图谱聊天、源码讲解和 DSH 图谱编辑指引共用入门讲解规则：先说明中文角色和用途，再对照源码名词；动作有执行者、对象和接收方；术语首次出现时解释类别及作用；不以“拉、回送、消费”等速记代替数据流说明；假设例子和已核对的事实分开。

已有节点的概览页提供“请曳尔沐翻译术语”。桌宠把当前节点原文、已有关系和本地已核对源码片段交给 AI，生成后再审读。术语翻译和流程对照保存在独立的 ReadingGuide 中，Summary、Approach、代码、来源、关系及用户复述都不改写。原介绍始终可读；概览中的“实现原文 / 术语翻译 / 流程对照”分别呈现原说明、保留原始拼写的定义、逐步对应的代码解释。翻译完成后直接显示术语页。

流程对照逐字引用介绍或实现说明中的片段，再解释对应函数、语句和数据流。跳转链接只允许使用本轮已读取并核对的固定源码；未定位则明确标注。原文变化后旧翻译会标记可能过期。失败或并发版本冲突保留已有内容；术语条目覆盖和链接校验不代表 AI 的语义解释已获人工认证。

这项能力按需调用，不批量覆盖现有图谱。它改进 AI 的写作过程，不预置某个仓库的人工解释模板。

### 页内咨询

图谱顶部提供咨询输入框，Enter 发送、Shift+Enter 换行，回复可展开或收起，并与陪伴对话同步。发送时捕获当前专题、模块、节点、说明页签及可读取的固定版本源码上下文；之后切换视图不改变该次问题的范围。

全屏使用相同的咨询输入控件，保留草稿与回复展开状态。

### 多级模块

模块的 `ParentId` 表示同仓库父模块，省略或为空表示根；旧版平铺图谱无需迁移即可读取。每层只展示直属子模块和直属源码节点；节点只直接归属一个模块，数量、等级底边颜色和跨模块关系按后代汇总。导航路径可跳转任一祖先，“返回上级”逐层返回；总览只显示根模块。子树搜索会高亮其所属模块，节点跳转直接进入实际所属层级。全屏与窗口视图共享层级状态。

在当前模块上方或说明框点击“请曳尔沐创建 / 调整子模块”，也可直接在咨询框提要求，例如“在当前模块创建模型执行子模块，再建立前向与输出处理子模块，把已有 Runner 节点移进去，保留其他内容”。这些是学习组织关系，不代表新的代码调用证据。空模块允许逐步补充，不自动生成未经核实的代码细节。现有专题不会被自动重新分类。

编辑协议新增 `Modules: [{Id, Title, Repository, Summary, ParentId}]`，按 ID 增量创建或修改；字段省略则保留，`ParentId: ""` 可将模块移到根。与 `NodeModules` 一起即可创建子模块并移动节点，保存成功返回可定位模块的结果。Modules 不与整体 Architecture 替换混用；父模块缺失、跨仓嵌套、循环、重复 ID、超过 12 层或 60 个模块均拒绝整次修改，仍检查图谱版本并在保存失败时回滚。原节点介绍、来源、关系和请求旅程不因整理层级而改写。

无子模块且仅有一个直属源码节点的模块以“源码节点 · 点击阅读”显示，直接打开该源码节点说明与代码入口，不再显示展开操作。层级数据保留；全屏说明框锚定原卡片，咨询与编辑使用真实源码节点。含子模块、多节点或空模块仍保留展开。
