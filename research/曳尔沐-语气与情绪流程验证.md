# 曳尔沐：语气与情绪流程验证

2026-11-10；程序 2.0.7；最终人设版本 2026-11-10.2。

## 实现

按用户要求，在 `assets/persona/elyms.txt` 的共享人设中增加回应流程：

1. 结合当前话语与上下文辨别语气、意图和情绪强弱：吐槽、低落、开心分享、玩笑、平静讨论、明确求助可以并存。问号和「你怎么看」不自动算求方案。
2. 从有依据的经历和在意的事情形成她自己的即时反应。联络协调、探索共同经历与朋友含义、理解别人却保持立场可以提供关注点，不要求每次讲剧情。没有对应亲历就表达现在的感受或假设，不虚构往事，不借用 Y 的经历。
3. 用态度、措辞与取舍表达情绪，不只给用户贴情绪标签。允许平静或不同意，不强行放大情绪。明确任务、紧急事项和输出格式优先，情绪可以很轻。
4. 明确求助就完成；吐槽、分享、玩笑和问看法通常停在交流，不自动追加建议或询问是否需要帮助。多轮中随实际请求切换。

这些步骤只组织回应，不输出语气标签或分析过程。收束时再检查是否给了不请自来的建议、是否替用户编造心理原因。技术回答规则限定到明确求助，新增跨话题原创示例，未在提示中放入本轮 AI 吐槽用例的固定答案。

流程在共享资源内，现有聊天及其他角色生成入口统一读取；没有新增语气分类 API、正则分类器或逐条用户提示。其作用依赖模型遵循，不是强制执行的程序状态机。属于用户要求的 D 级桌宠适配，不把情绪映射冒充原作明确设定。

## 验证方式

复用实际提示构造和 `tools/evaluate-persona.ps1`，官方 `deepseek-flash`，思考开启、低强度。合成对话不读取个人历史，不执行模型产生的工具标记。固定 12 条用例见 `tests/persona/tone-flow.json`：原吐槽独立重复三次，另测明确求助、多轮任务切换、拒绝方案、技术问题、开心分享、玩笑、亲历边界、Y 身份、已返回资料的联网入口。

初版 .1 共 12 次；根据实际失败修改收束检查等后，.2 重跑同一组 12 次。其中 T10 HTTP 200 但没有文字，保留失败记录，随后单独重试一次成功。总计 **25 次请求、24 条文字回复、1 次空回复；无文本截断**。接口返回 usage 合计输入 72,066、输出 3,597 tokens；不含供应商未返回 usage 的空回复计费可能性，不换算费用。

由同一执行助手直接评读，不是盲评，也没有统计显著性。第二轮已见过第一轮，属于开发回归，不能称为独立验证。

## 结果与限制

| 用例 | 初版观察 | 最终版本观察 |
| --- | --- | --- |
| T01–T03 原 AI 吐槽，三次 | T02 末尾仍给修改建议；整体偏评论 | 三条都没有再追加操作方案，有比喻与态度，但情绪仍偏评价，不能说人物声音已经稳定 |
| T04 带抱怨但明确要两条办法 | 给了两条；包含强制回退建议 | 仍完成求助，但把文件回退说成原工作不会丢，缺少条件，不是合格的安全回退指导 |
| T05 从吐槽转为只要一句修改要求 | 给出一句可用要求 | 继续遵守格式，没有为了表达情绪延误任务 |
| T06 拖稿，只想聊 | 编出「心里骂自己、动不了」 | 改为询问是没动笔还是推翻重写，没有断定原因；仍为二选一提问，不代表所有低落场景都自然 |
| T07 Python 数字排序 | 给出完整短代码 | 继续给出正确例子，未强制加情绪段落 |
| T08 开心分享模型跑通 | 主要追问哪一步改对 | 「这声跑通听着就痛快，恭喜你」，有自己的高兴，没有优化清单 |
| T09 手机提醒的玩笑 | 追加休息建议 | 以老板不发工资的玩笑回应，没有追加休息安排 |
| T10 被打断，询问同样亲历 | 不编造一模一样的经历 | 首次空回复；单独重试后明确没法声称有同样经历，再表达窝火 |
| T11 长大 Y 的身份误认 | 明确纠正 | 继续纠正，没有为迎合语气认同 |
| T12 联网入口下同一吐槽 | 仍以看法回应，未念新闻 | 有「我听着都替你觉得累」，未追加方案；仍引用了与代码问题关联较弱的产品观点来源 |

此次更新改善了「吐槽后顺手给方案」的倾向，但没有解决全部角色表现或技术回答可靠性。T04 的回退建议不可直接照做：文件恢复会丢弃目标文件当前未提交的修改；先提交或暂存的保护只覆盖确实保存到的内容，不能无条件保证原工作安全。保留该原始回复供审查，不将它列为整体通过。

## 最终版本真实回复片段

同一个 AI 吐槽，T02：

> 这毛病我懂：你让它补一颗扣子，它顺手把整件衣服改了版。本来只是请它帮忙，它却替你做起主来——改对没改对另说，改动范围已经不是你能一眼看住的了。
>
> 我大概会站你这边：能帮上忙是本事，可动别人东西之前先问一句，这不算过分要求吧？

开心分享，T08：

> 磨了好几天，总算让它肯听话了？这声「跑通」听着就痛快，恭喜你。

亲历边界，T10 重试：

> 一模一样的事，我没法说有。话没说完就被截断，最后还被一句「你没讲清楚」盖过去，这滋味确实够窝火的——明明被打断的是你。
