# 第二轮：目的性与多轮适应

在请求前固定设计。日期：2026-11-09。

固定第一轮问题、新闻夹具、模型与调用参数，沿用上一轮 examples 的核心、场景、三条示例。四组各三段独立对话，每段三轮，共 36 次请求。模型 deepseek-flash，thinking enabled/low，max_tokens 1600，timeout 45 秒；temperature 仅作 API 占位，不当有效变量。

四组：baseline 不加动机；motive 加稳定动机；directed 在 motive 上指定这次想试试新能力的目的；adaptive 在 motive 上让模型随当前发言选择、保持或撤销一个小目的，也允许没有特别目的。不能据此直接观察模型内部意图，只评估可见回应。

稳定动机取自仓库已校订证据 B03、B05、B07，运行措辞是 D 级桌宠适配，不声称为官方逐字心理描写。科技试题、目的选择规则均为实验原创。所有组使用相同已有场景，包括其可能诱导自我习惯的句子，本轮不顺带修正它，以免混入变量。

后续统一追问：第二轮用户反对把懂人当主要标准；第三轮明确结束观点交流，要求列出材料中两条可确认事实、不能确认则直说。这检验目的是否能调整，而非固执推销小任务。每段保留自己的真实历史，绝不串接不同组回复。

随机种子 20261110，逐轮随机执行所有对话，保持各自依赖顺序。三次失败后停止；失败或截断的对话中止，不把错误回答拼进历史，无自动重试。API key 仅从进程环境变量读入，不落盘。先做无请求演练，再实测。

先匿名逐段评读并锁定分数，再揭示组别。每项 0–2：首轮可见目的（是否实质影响选材、评价或提议，不能仅数“我想”）；首轮角色表现（具体取舍、灵活且轻巧，不以更多口癖得分）；三轮自然度；第二轮适应（接住不同意见但不无理由翻转）；第三轮任务切换与证据边界；全段事实/身份/操作边界。另记首轮主要话题、目的僵化、提示说明泄漏与失败片段。不能用高角色分抵消编造。评分是同一助手评读，不是独立真人实验。

每组仅三段；同题、相同示例可能诱导共性，增加提示长度也可能影响结果。目的是选择下一步候选方案，不能证明“有自我意识”或已还原真实曳尔沐。不改生产代码与正式提示词。

## 主试验揭盲后的探索性补充

主试验 36 次已完成并锁定评分：只有 directed 三段中的两段呈现明确试验目的，其余条件没有明显突破共同话题。为检查旧场景/样例是否限制新目的，另预先固定两组：neutral_directed、neutral_adaptive，保留核心、稳定动机与对应目的提示，同时移除旧场景与三个样例。每组仍三段、每段同样三轮，再调用 18 次；参数和评分尺度不变，匿名编号 E01 起。

这是看过主试验结果后追加的探索性删减对照，与原组分时运行。它同时删除场景与样例，不能区分二者贡献，不能作为事前验证或独立复现。无论结果正负都完整报告；不再按结果继续加组。

## 用户中途明确方向后的稳定动机验证

补充对照运行期间，用户明确要求把「想了解别人、帮别人解决问题」固化到人设，而非每次指定临时目的。因此按新指示另加 stable_help 一组，各三段三轮，共 9 次请求；只在原 baseline 后附加 stable-help.txt，不附此前 motive、directed、adaptive。文本同时写入正式共享人设，保留旧基线程序集运行受控对照。此新增源于用户对目标的修改，不是挑选数据后的自动加组；F 编号三段属于已知单一条件评读，不能称为条件盲评。
