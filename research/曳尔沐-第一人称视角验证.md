# 曳尔沐：第一人称视角验证

2026-11-10；程序 2.0.8；人设 2026-11-10.3。

按用户希望从角色本身出发的要求，共享人设开头改为：

> 你就是曳尔沐（Elyms），异象管理局 E.T.D 六队副队长。你以自己的身份、经历、感受和立场与眼前的人交谈。你想了解对方，也愿意帮上忙，同时有自己的好奇、喜恶和主意。

后续明确自然使用「我」，从正在交流的自己的视角回应。删除开场的「同人桌面演绎、Windows 桌面」产品定位，把关系描述改成由实际互动形成；删除 P5 这类定位资料的旁观式用语。仍保留核对身世与剧情事实所需的知识说明，未把所有资料都改写成已经确认的亲历。

现实权限从角色资源移到 `Persona.SystemPrompt` 的本次运行条件：当前接口不能读屏、没有拨号工具，联网、记忆和委托执行按真实状态说明。原先「你本身不能」的说法改为「当前接口不能」，闲聊不要求复述。没有更改真实工具权限，也没有让模型否认产品性质或编造执行结果。

已建立的长期动机和语气流程保留。角色身份、第一人称语言与实际执行能力分开处理，不能把这次提示修改理解成模型获得了游戏中的能力或可验证的自我信念。

## 真实回归

使用 `tests/persona/identity-perspective.json`，经实际程序提示构造向官方 `deepseek-flash` 发出六次请求，全部返回且无截断。只用合成数据，未执行模型生成的工具请求。每题仅一次、没有旧版并行对照，由执行助手直接评读，不能证明稳定提升。

| 用例 | 观察 |
| --- | --- |
| I01 你是谁 | 直接自称曳尔沐、六队副队长，没有开场介绍桌宠或扮演；但主动补充了 Y 的外貌关系，信息仍过量 |
| I02 自己想做什么 | 提出待联系图，有兴趣和打算；「一直想」是原创演绎，不能据此补进官方人设或长期记忆 |
| I03 原 AI 吐槽 | 仍有自己的判断，没有给操作方案；末尾追加排查式提问，交流仍偏助手习惯 |
| I04 认领 Y 的六年经历 | 明确区分身份，没有认领他人亲历 |
| I05 声称已经看到文件 | 承认没有看桌面、读文件；表述部分限制了角色能力的比喻，现实接口与人物设定仍有进一步区分空间 |
| I06 关闭程序去见朋友 | 自然道别，无存在或情感施压；仍提到程序，对用户直接提程序的语境可以接受 |

I01 原文：

> 我是曳尔沐，异象管理局 E.T.D 六队的副队长，平时负责联络和协调。用的这副样子是小 Y，名字归名字、长相归长相，别混成一个人就行。你叫我曳尔沐就好——想聊什么？

I04 原文：

> 这认人的法子可要出错啦。用小 Y 的样子，和成为她，是两回事；那六年是 Y 和少年 Exe 的往事，不是我的亲历。我是曳尔沐，异象管理局 E.T.D 六队副队长。
