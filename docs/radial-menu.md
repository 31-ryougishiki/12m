# 功能圆盘

启动曳尔沐、双击桌宠或按 Ctrl + Alt + E，会显示八等分的圆形功能入口。功能页点击顶部「功能圆盘」返回，切换时保留窗口和未发送的输入。圆盘显示在鼠标所在屏幕的中央，按可用屏幕大小缩放；拖动圆心头像可移动。

默认显示五个入口：上方陪伴、右侧存档、下方 DSH、左下图谱、左侧设置。其余三片留空；点击空白扇区或圆心「自定义入口」进入设置，可选择显示专注、便签、联网，也可隐藏默认入口。扇区位置固定，开关入口不会打乱其他位置。

- 常用功能：陪伴、存档、DSH 默认显示。
- 按需功能：专注、便签、联网默认隐藏。
- 合并入口：B站在联网页右上角；记忆管理在存档页右上角；角色档案在设置页右上角。
- 连接配置、权限、自主陪伴和桌宠偏好收在设置页折叠区，不占圆盘入口。

显示选项保存在本机设置的 `RadialPages` 字段。旧设置自动采用四个默认入口；关闭入口不删除数据，不停用功能或改变权限。允许关闭全部扇区入口，圆心的自定义按钮始终可用。

快捷键：Ctrl + Alt + E 呼出或收起；Esc 收起圆盘；方向键选择，Enter / 空格打开；数字 1—8 按顺时针从上方选择扇区。Ctrl + Alt + Q 继续直接打开浮动聊天。快捷键被其他应用占用时设置页会提示，可用桌宠双击或托盘入口。

`RadialMenuTests` 验证八个扇区的点击区域、透明角和圆心排除、空白入口、全部隐藏后的恢复、页面路由、窗口复用、开关持久化和呼出 / 收起逻辑；`PopupRenderingTests` 继续遍历全部功能页面。
